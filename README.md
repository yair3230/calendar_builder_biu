# Calendar Builder BIU
This creates a ICS file that you can import in your Google calendar.

## Dependencies
To ensure this works, install python, and run on your computer
`pip install beautifulsoup4`

## How to
1. Go to In-bar and download the schedule.

   
   ![step 1](https://i.postimg.cc/wB16hfjf/step1.png)
2. Name the file "input.htm" and save it IN THE SAME FOLDER of the code.
![step 2](https://i.postimg.cc/9XYjq5Bq/step2.png)

3. Run the code, give it the start and end date of the semester.
![step 3](https://i.postimg.cc/bJ04bkkm/step3.png)

4. Import the ICS file in Google calendar
